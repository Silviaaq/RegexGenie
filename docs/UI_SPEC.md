# RegexGenie UI

All application-owned copy is English. Source data and filenames are unchanged.
Desktop first, neutral surfaces and one cool blue accent (#3069d4). No external
font requests: system sans-serif UI, monospace regex/data/line numbers. Fine borders,
small radii, restrained shadows. Comfortable 43px rows, compact 32px rows.

Prepare: file picker/drop, limits, sample, sheet selection, filename/row/column
counts, original paginated table, instruction, clickable and copyable examples,
optional replacement, explicit empty-text checkbox, Generate Preview, privacy note.

Review: filename/sheet, English interpretation, collapsible read-only JSON rule,
Original/Preview tables, matching column widths/row heights, synchronized scroll,
fragment counts and active match navigation. Match lookup fetches its page even
when the first match is beyond page one. Page footers show total rows. Edit returns
to the original data. CSV/XLSX downloads include all rows, never just the visible page.

Other matches have a light blue fill; current match has a darker outline. Deletion
uses ∅ with Content removed tooltip; it is not exported. Zero matches is successful
and displays 0/0. Errors preserve editable input and describe a next action.

Temporary notice: Files are temporary. Download your results promptly. You may
need to upload again if the service sleeps or restarts.

Mobile stacks comparison panels and permits horizontal table scrolling. Full
browser, keyboard and mobile device acceptance remain to be performed on deployment.
